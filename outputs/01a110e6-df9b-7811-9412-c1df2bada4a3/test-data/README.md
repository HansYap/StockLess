# StockLess 合成测试文件

这些数据均为生成的虚构数据，用于功能测试，不计入至少 12 份真实 CSV 的正式验收集。

预期结果的参考分析日期：2026-10-06。新上传文件使用应用当前的马来西亚日期；2026-10-07 的完整周范围和本包预期相同，库存年龄为2天。之后测试时，完整周和库存新鲜度结果可能改变，需相应更新文件日期；无需修改电脑系统时间。成本币种 MYR，销量/库存/采购成本均按同一个销售单位；重量按每销售单位公斤。

## 开始测试

1. 先上传 01_clean_english.csv。按列名确认销售日期、商品代码、销量；可选名称、包装、库存、库存日期、单位成本、单位重量也对应映射。选择商品代码作为标识。交易参考列保留在文件中，不需要映射。
2. 运行 Step 3，应该得到 24 条使用记录、0 条排除。Tea 的 SKU 000101 保留前导零。
3. 进入采购页，不输入订单时多余库存汇总应为“未输入”。Tea 输入 40 件时，采购成本应为 MYR 100.00；输入 0 是有效订单，不能当成未输入。
4. 展开供应商比较。真实文件的两组条件需要自行填写；例如 A 箱规6、最低24、交期2，B 箱规12、最低60、交期9。只有点击使用数量才改变计划，不会自动发送订单。
5. 其他文件逐个测试，详细列映射和预期结果在 expected-results.json。
6. Excel 文件必须选择 Sales：标题行在第3行，24条记录在第4至27行。选择 Other shop 时只应导入8条记录。

## 为什么至少12份

US1.4 AC7 指定至少12份真实商户CSV，以覆盖英文、马来文、缩写和不明确表头。它检验列建议的准确率和覆盖率，不要求每次上传12份，也不是运行系统的最低数据量。一份文件就能开始功能测试。这7份合成文件帮助复现功能与边界，但不能声称通过真实CSV验收。

Impact Dashboard 按用户要求保持原样，金额接入暂缓，本测试包不把它列为已完成项。
